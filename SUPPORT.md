# Support

Adslop is in its specification and repository-foundation stage.

Repository members can open an issue for a reproducible bug, a scoped feature request, or a development question. Include the commit or version, operating system, Python or Node.js version, command run, expected behavior, and complete relevant error output.

The application and advertising integrations are not yet available. Product questions should refer to the relevant section of [SPECIFICATION.md](SPECIFICATION.md).

Report vulnerabilities privately using [SECURITY.md](SECURITY.md).
